Musik Latar

Pilih lagu pengiring saat tamu membuka undangan. Lagu otomatis diputar saat tombol "Buka Undangan" diklik.

💡 Biarkan kosong jika ingin menggunakan nada melodi lembut bawaan.

💡 Cara Terbaik & Paling Pasti Bunyi:

⭐ Opsi 1: Taruh File di Folder Project (Paling Direkomendasikan)

1. Simpan file lagu format .mp3 Anda ke dalam folder assets/ di project (misal: assets/musik.mp3).
2. Ketik assets/musik.mp3 pada kolom URL Musik di atas lalu simpan.
3. Saat di-upload ke Cloudflare Pages, lagu di-hosting langsung dan 100% pasti berputar lancar tanpa buffering / blokir.

⭐ Opsi 2: Link Dropbox (Otomatis Didukung)

Upload MP3 ke Dropbox > Salin link bagikan > Paste di kolom atas. Sistem kami otomatis mengonversinya menjadi direct audio stream.

⭐ Opsi 3: Upload Gratis ke Catbox.moe

Buka catbox.moe (tanpa daftar/login) > Pilih file MP3 Anda > Klik Upload > Salin link https://files.catbox.moe/...mp3 > Paste di kolom atas.

⚠️ Catatan Google Drive Audio: Sejak update keamanan 2024, Google Drive memblokir pemutaran file audio MP3 langsung di browser web luar (Error 403 Forbidden). Untuk foto di Google Drive tetap aman dan lancar, namun untuk file musik disarankan menggunakan Opsi 1 (folder assets/) atau Opsi 2 (Dropbox / Catbox) di atas.
